# MoneyMint

Loan Management System (college assignment).

MERN stack: Next.js + Express + MongoDB + TypeScript.

App code is not in yet. This repo is just the starting setup.

## Git flow we are using

- `main` stays clean
- each feature goes on its own branch (`feat/...` or `fix/...`)
- raise a PR, then merge it

Evaluator login accounts and setup steps will be added when the app exists.
